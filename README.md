Online Shopping Cart Website

Description

This project is an Online Shopping Cart Website designed to provide a seamless and user-friendly experience for online shoppers. It allows users to browse products, add them to a shopping cart, and proceed to checkout. The website is built using modern web development technologies to ensure responsiveness and interactivity.

Features

Responsive Design: Ensures compatibility across various devices and screen sizes.

Dynamic Product Display: Products are displayed dynamically using Angular components.

Shopping Cart Functionality: Add, update, and remove products in the cart.

Bootstrap Styling: Clean and professional UI using Bootstrap framework.

Interactive UI: Enhanced interactivity with Angular and TypeScript.

Technologies Used

HTML: Structure of the website.

CSS: Styling and layout.

Bootstrap: Responsive design and pre-styled components.

Angular: Framework for building the application.

TypeScript: Strongly typed JavaScript for scalable and maintainable code.

Installation

Clone the repository:

git clone https://github.com/yourusername/online-shopping-cart.git

Navigate to the project directory:

cd online-shopping-cart

Install dependencies:

npm install

Start the development server:

ng serve

Open the application in your browser at http://localhost:4200.

Usage

Browse through the products listed on the homepage.

Add products to the cart by clicking the "Add to Cart" button.

View your cart and adjust quantities as needed.

Proceed to checkout to finalize your order.

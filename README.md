                                                                            ONLINE SHOPPING CART

Overview :

The Online Shopping Cart is a web-based application designed to provide users with a seamless shopping experience. This project is built using modern front-end technologies, including HTML, CSS, Bootstrap, Angular, and TypeScript, to deliver a responsive and dynamic interface.

Features :

 - User-friendly interface with a responsive design

 - Product listing with filtering and sorting options

 - Shopping cart functionality (add, remove, update quantity)

 - Dynamic price calculation

 - Smooth navigation with Angular routing

 - Secure and structured TypeScript implementation

Technologies Used :

Frontend: HTML, CSS, Bootstrap

Framework: Angular

Programming Language: TypeScript

Installation and Setup :

Clone the repository:

 - git clone https://github.com/your-username/online-shopping-cart.git

Navigate to the project directory:

 - cd online-shopping-cart

Install dependencies:

 - npm install

Run the development server:

 - ng serve

Open your browser and navigate to:

 - http://localhost:4200

Usage :

 - Browse the available products

 - Add products to the shopping cart

 - Adjust quantities or remove items as needed

 - Proceed to checkout (future enhancement)
